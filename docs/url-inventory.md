# URL inventory — peptidescostarica.net

Harvested from the live home page's own links on 2026-07-26 (97 internal paths).
Every path here must exist at the same path after cutover, or carry a 301.

> This is the home page's link graph only. Category and product pages will link
> to paths not listed here — re-harvest per page before the launch audit.

## Not in the original brief

These turned up on the live site but were missing from the project brief. Worth
flagging because each one is live SEO surface:

- **A whole second product namespace: `/product/*`** (23 URLs below). The brief
  described only the `/<name>-costa-rica/` pattern. Both exist. The
  `-costa-rica` pages look like marketing landing pages; `/product/*` are the
  WooCommerce product objects.
- `/info-center/`
- `/peptide-guides/`
- `/customer-feedback/`
- `/our-service-locations/`
- `/html-sitemap/`
- `/privacy-policy/`
- `/shipping-policy/`
- `/return-refund-policy/`

Also note two category slugs use the **singular** "peptide", which is easy to
typo into a 404:

- `/peptide-for-cognitive-function/`
- `/peptide-for-cardiovascular-costa-rica/`
